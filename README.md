# qa-coupon-testing
Manual QA testing portfolio for a coupon checkout system.
# 購物網站優惠券功能測試 | QA Portfolio

## 專案介紹

本專案為個人 QA 學習作品，針對模擬購物網站的優惠券功能進行手動測試。

測試目的是確認系統是否符合功能需求，包含優惠券使用條件、金額限制、大小寫驗證與重複使用限制。

本專案為模擬測試練習，非企業正式專案。

## 測試範圍

- 優惠券正常使用流程
- 最低消費金額限制
- 優惠碼格式及大小寫驗證
- 優惠券重複使用限制
- 同筆訂單優惠券併用限制

## 使用工具與技術

- Google Chrome
- Manual Testing
- Test Case Design
- Boundary Value Analysis
- Bug Reporting
- Markdown / GitHub

## 測試成果

於實作練習中發現三類功能缺陷：

**Bug 1：優惠券重複使用**

同一位使用者成功使用優惠券後，仍可再次使用，違反每人限用一次的規則。

**Bug 2：優惠碼大小寫驗證異常**

輸入與規定優惠碼大小寫不一致的內容，仍可成功套用優惠券。

**Bug 3：最低消費金額判斷異常**

購物車商品小計剛好達到 NT$1,000 時，系統錯誤地判斷未達優惠門檻。

## 測試方法

依據功能規格設計正常流程、異常流程與邊界值測試，記錄預期結果和實際結果，並整理可供重現的 Bug Report。
